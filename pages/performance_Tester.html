Throughput benchmark

Each test runs for exactly 1 second and counts how many increment operations complete. CPU and WebGPU run independently, in the same tab, with nothing else changed between machines.

CPU (JS, single thread)

Increments a running counter as fast as possible for 1 second. No array is pre-allocated — that would try to reserve billions of elements up front and crash the tab before the test even starts. Counting up a number in a loop measures the same thing without that problem.

WebGPU (compute shader)

Runs the same kind of increment, but on the GPU across many parallel threads at once, repeated for 1 second.
